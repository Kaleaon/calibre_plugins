# Calibre plugins

Plugins for [Calibre](https://calibre-ebook.com) 6 or newer (Windows, macOS, Linux). To install one: download its ZIP below, then in Calibre choose **Preferences → Plugins → Load plugin from file**, pick the ZIP, and restart Calibre. If the plugin's button is not visible, add it under **Preferences → Toolbars & menus**.

## Metadata sources

Every plugin above (except Calibre Link, which is the bridge that *uses* metadata sources) also ships as a Calibre **metadata source**, so it can answer **Download metadata** / identify requests with the same site logic it downloads with. Calibre registers exactly one plugin per ZIP — the first plugin class in it — so each source is a separate small ZIP that reuses its plugin's own search code. Install the ones you want the same way (Preferences → Plugins → Load plugin from file); they then appear in Calibre's **Download metadata** source list, where you can enable or disable them per lookup. The sources share their plugin's saved settings (logins, API keys, rules).

- [TakeoutGoogleBooksSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/TakeoutGoogleBooksSource.zip) — **Takeout Google Books**: Google Books metadata and covers, mapped from `volumeInfo` exactly the way the Takeout Book Fixer maps Takeout sidecars. Search by title/author or ISBN; direct lookup by Google Books volume id.
- [EpubPromoScrubberSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/EpubPromoScrubberSource.zip) — **Promo Scrubber**: returns the book's own title with promo-site marks (OceanofPDF, PDFDrive, …) removed, using the scrubber's patterns. Title only; returns nothing when the title is already clean.
- [MetabodsMetadataSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/MetabodsMetadataSource.zip) — **Metabods**: full story metadata (author, tags, categories, summary) by `metabods` story id or story URL; by author via the site's author index (Metabods has no title search).
- [NiftyMetadataSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/NiftyMetadataSource.zip) — **Nifty**: title/author/date by `nifty` archive path or story URL, and by author + title through the archive's author directory (only the first chapter is read).
- [FanficMetadataSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/FanficMetadataSource.zip) — **FanFicFare Sites**: metadata-only FanFicFare pass for a book whose `url` identifier points at a supported site (Royal Road, AO3, 100+ more) — title, authors, description, tags, series, language, dates, cover when the site offers one. The downloader's adult-sites and advanced settings apply.
- [StoryCollectionTaggerSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/StoryCollectionTaggerSource.zip) — **Story Source Tagger**: tags only — the `Source.<Site>` tags and keyword-rule tags the tagger would add, worked out from the book's identifiers.
- [RedditMetadataSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/RedditMetadataSource.zip) — **Reddit Stories**: searches Reddit (public feeds, or the official API with the follower's credentials) by title or author and groups posts into series and single stories, like the follower's discovery.
- [GeminiMetadataSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/GeminiMetadataSource.zip) — **Gemini Metadata**: the fixer's provider enrichment (Metabods / Nifty / FanFicFare / Open Library identifiers) plus, when a Gemini API key is saved, a validated Gemini cleanup of title, authors, series, tags, language and ISBN.
- [ClaudeMetadataSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/ClaudeMetadataSource.zip) — **Claude Metadata**: the fixer's provider enrichment (Metabods / Nifty / FanFicFare / Open Library identifiers) plus, when an Anthropic API key is saved, a validated Muse cleanup of title, authors, series, tags, language and ISBN.
- [MediaMatcherMetadataSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/MediaMatcherMetadataSource.zip) — **Media Matcher Lookup**: MusicBrainz recordings (album as series, track as series number, Cover Art Archive covers) and Open Library books/audiobooks, scored with Media Matcher's matching. Direct lookup by ISBN, MusicBrainz id or Open Library id.
- [InkbunnySoFurryMetadataSource.zip](https://github.com/Kaleaon/calibre_plugins/raw/refs/heads/main/dist/InkbunnySoFurryMetadataSource.zip) — **Inkbunny & SoFurry**: Inkbunny API search by title and lookup by submission id (using the downloader's saved login or guest access); SoFurry by submission id/URL and by author gallery, with the saved SoFurry token when one is set.

## Bulk install and update

With 25 ZIPs in the pack, installing them one by one is nobody's idea of fun. Three ways to do it in bulk:

- **Inside Calibre — the Plugin Pack Manager** (last row of the table above). Install that one ZIP once, restart, and its menu handles the rest: *Install / update all plugins…*, *Check for updates…* (a one-file hash check), and *Install from a local folder…* for offline installs.
- **From the command line — [`install_all.py`](install_all.py)** drives `calibre-customize -a` for every pack ZIP: `python install_all.py` installs from `dist/`, `--download` fetches the latest builds from GitHub with hash verification, `--folder PATH` installs from any folder of ZIPs, and `--copy-to DIR` copies straight into a calibre plugins folder (portable installs, with Calibre closed). It skips downgrades unless `--force` is given. `install-all.bat` / `install-all.sh` are thin wrappers around `--download`.
- **One-file bundle** — `python install_all.py --make-bundle CalibrePluginsPack.zip` packs every ZIP plus the installer and instructions into a single file you can carry to another machine and install from, offline, through the manager's local-folder mode or the script.

## Releases

The download links above serve the plugin ZIPs committed in the [`dist/`](dist/) folder on the main branch, so they always give you the latest packaged builds and never depend on which GitHub release happens to be marked "latest". Each time a release is packaged (a version tag matching `v*.*.*` is pushed), GitHub Actions builds all plugin packages in strict mode, calculates SHA256 hashes, attaches the plugin archives along with a `SHA256SUMS.txt` cryptographic manifest to the release on the [Releases page](https://github.com/Kaleaon/calibre_plugins/releases), and commits the same freshly built ZIPs back into `dist/` on main — which is what updates the downloads on this page.

## Building and testing

Build every plugin zip with `python build_plugins.py` (output in `dist/`). The Fanfic Site Downloader zip bundles FanFicFare and needs `pip install fanficfare` in the Python that runs the script; otherwise that one zip is skipped with a message, and `--strict` turns that into an error. Shared code for the story plugins lives in `common/` and is copied into each zip.

Run static linting with `ruff check .` and formatting checks with `ruff format --check .`. Run the test suite with `python -m pytest tests/`. Offline tests cover the Metabods and Nifty parsers, text cleaning, EPUB structure, the tagger, the fanfic engine and its zip contents, and an import check of each built zip under stubbed Calibre and Qt modules. The fanfic tests need `pip install fanficfare` and skip without it; `tests/test_media.py` covers Media Matcher (its real-encoder tag tests skip without `ffmpeg`), `tests/test_media_dialogs.py` runs its windows under PyQt6, and `tests/test_qt_dialogs.py` runs the real dialogs under PyQt6 (`pip install PyQt6`; on Linux it may also need system libraries such as libEGL) and skips without it. The one failing test in a plain environment is the older PDF test, which needs PyMuPDF.

Against the live sites: 30 random Metabods stories plus a 50-part one, and 26 Nifty books across all four sections (including a 58-chapter series, `.html` chapter files and odd subjects) all produced well-formed EPUBs. One Archive of Our Own story (chapter 1) was downloaded through the engine from the built zip in a clean environment; Royal Road was not reachable (see the [Fanfic Site Downloader docs](fanfic/README.md)). **Not tested inside Calibre itself** (it was not available here): the dialogs, menus, library import, tag application and refresh. The Calibre calls used (`add_books`, `all_field_for`, `get_metadata`, `set_field`, `refresh_ids`, `JSONConfig`) were checked against Calibre's source on GitHub, and the modules were import-checked against stubs.
## Real Takeout validation

Version 1.0.1 was tested with the shared January 2025 export part 003: all 51 books recovered and imported into Calibre 9.15 with no errors. Content inspection identified 47 EPUBs and four PDFs; 16 of those EPUBs had been named `.pdf`. Calibre recovered known authors for 48 books and covers for all 51. Takeout ZIPs are streamed per member, allowing the archive itself to exceed the individual-book size limit. Other parts of the export and the full October 2026 export were not validated.

Optional comic conversion was also verified with both real image-only PDFs (45 pages each): all pages rendered and both CBZs imported successfully. Both text-bearing PDFs stayed PDF. Lossless rendering took several minutes per comic in this environment.
