# Calibre plugins

Plugins for [Calibre](https://calibre-ebook.com) 6 or newer (Windows, macOS, Linux). To install one: download its ZIP below, then in Calibre choose **Preferences → Plugins → Load plugin from file**, pick the ZIP, and restart Calibre. If the plugin's button is not visible, add it under **Preferences → Toolbars & menus**.

## Releases

Official plugin releases are published on the [Releases page](https://github.com/Kaleaon/calibre_plugins/releases). When a version tag matching `v*.*.*` is pushed, GitHub Actions builds all plugin packages in strict mode, calculates SHA256 hashes, and attaches the plugin archives along with a `SHA256SUMS.txt` cryptographic manifest to the release.

## Status

- Takeout Book Fixer 1.0.1 was validated with Calibre 9.15 on Linux against a real 51-book Takeout sample (see the validation notes). Version 1.1.0 adds the library repair command, which was not part of that validation run.
- EPUB Promo Scrubber has unit tests for its cleaning logic only. The Calibre menu and library-saving code has not been run inside Calibre, and no real-world EPUBs have been tested.
- Reddit Story Follower: its feed parser was checked against a real r/HFY feed and against the real first post of Out of Cruel Space (by KyleKKent; the rest of that series was not fetched); the search-feed form, page-by-page backfill and the official-API path and Log in with Reddit are not verified live (Reddit rate-limited the test requests, and no API credentials were available). The rest is tested with stand-ins under real Qt, not inside Calibre. See its README.
- Gemini Library Fixer has offline tests for its request handling, answer checking and batching against canned Google responses. Its window was run under real Qt against a stand-in library (including generated cover images), but it has not been run against the live Gemini API (no key was available) or inside Calibre, so how well it reads real covers is untested. See its README.
- Media Matcher has offline tests for its tag readers (checked against files written by ffmpeg in every supported format, plus hand-built and damaged files), its service clients and its matching, using responses recorded from MusicBrainz and Open Library. The lookup, scoring and cover download were run against the live MusicBrainz, Cover Art Archive and Open Library services; `fpcalc` output was checked against Chromaprint 1.5.1. Its windows were run under real Qt against a stand-in library. It has not been run inside Calibre, and a successful AcoustID fingerprint lookup was not possible (it needs a registered key). See its README.
- Metabods Downloader, Nifty Downloader, Fanfic Site Downloader and Story Collection Tagger have automated tests for their parsing, text cleaning, EPUB building, tagging rules and FlareSolverr helpers, and the downloaders were exercised against the live sites (30 random Metabods stories, 26 Nifty books, an Archive of Our Own story). None of the four has been run inside Calibre: their dialogs have been run under real Qt (PyQt6, offscreen) with Calibre stubbed and canned site pages, but Calibre's own menus, toolbar integration and library import are untested. Royal Road downloads are untested because Royal Road served a Cloudflare challenge to the test environment; the FlareSolverr setup is documented but unverified end to end.

## Building and testing

Build every plugin zip with `python build_plugins.py` (output in `dist/`). The Fanfic Site Downloader zip bundles FanFicFare and needs `pip install fanficfare` in the Python that runs the script; otherwise that one zip is skipped with a message, and `--strict` turns that into an error. Shared code for the story plugins lives in `common/` and is copied into each zip; the older Takeout Book Fixer is built by `build.py`.

Run static linting with `ruff check .` and formatting checks with `ruff format --check .`. Run the test suite with `python -m pytest tests/`. Offline tests cover the Metabods and Nifty parsers, text cleaning, EPUB structure, the tagger, the fanfic engine and its zip contents, and an import check of each built zip under stubbed Calibre and Qt modules. The fanfic tests need `pip install fanficfare` and skip without it; `tests/test_media.py` covers Media Matcher (its real-encoder tag tests skip without `ffmpeg`), `tests/test_media_dialogs.py` runs its windows under PyQt6, and `tests/test_qt_dialogs.py` runs the real dialogs under PyQt6 (`pip install PyQt6`; on Linux it may also need system libraries such as libEGL) and skips without it. The one failing test in a plain environment is the older PDF test, which needs PyMuPDF.

Against the live sites: 30 random Metabods stories plus a 50-part one, and 26 Nifty books across all four sections (including a 58-chapter series, `.html` chapter files and odd subjects) all produced well-formed EPUBs. One Archive of Our Own story (chapter 1) was downloaded through the engine from the built zip in a clean environment; Royal Road was not reachable (see the [Fanfic Site Downloader docs](fanfic/README.md)). **Not tested inside Calibre itself** (it was not available here): the dialogs, menus, library import, tag application and refresh. The Calibre calls used (`add_books`, `all_field_for`, `get_metadata`, `set_field`, `refresh_ids`, `JSONConfig`) were checked against Calibre's source on GitHub, and the modules were import-checked against stubs.
## Real Takeout validation

Version 1.0.1 was tested with the shared January 2025 export part 003: all 51 books recovered and imported into Calibre 9.15 with no errors. Content inspection identified 47 EPUBs and four PDFs; 16 of those EPUBs had been named `.pdf`. Calibre recovered known authors for 48 books and covers for all 51. Takeout ZIPs are streamed per member, allowing the archive itself to exceed the individual-book size limit. Other parts of the export and the full October 2026 export were not validated.

Optional comic conversion was also verified with both real image-only PDFs (45 pages each): all pages rendered and both CBZs imported successfully. Both text-bearing PDFs stayed PDF. Lossless rendering took several minutes per comic in this environment.
